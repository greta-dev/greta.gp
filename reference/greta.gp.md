# Gaussian process modelling in greta

A greta module to create and combine covariance functions and use them
to build Gaussian process models in greta. See
[`kernels()`](https://greta-dev.github.io/greta.gp/reference/kernels.md)
and [`gp()`](https://greta-dev.github.io/greta.gp/reference/gp.md)
