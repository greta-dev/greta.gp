# Changelog

## greta.gp (development version)

## greta.gp 0.2.3

CRAN release: 2026-07-21

- Resubmission to CRAN. `greta.gp` was archived in September 2025 as a
  consequence of its dependency, `greta`, being archived. `greta`
  returned to CRAN as version 0.6.0, and this release restores
  `greta.gp`.
- Now depends on `greta` version 0.6.0 or above.
- Fixed a grammatical error in the package `Description`.
- Fixed the r-universe installation instructions in the README, which
  referred to the wrong package.

## greta.gp 0.2.2
